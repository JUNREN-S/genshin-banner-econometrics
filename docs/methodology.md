# 实证分析格式规范 — 2026-05-26

**适用场景：** 所有 OLS/面板数据回归分析

## 输出结构（output/ 目录）

每次分析必须生成：
1. `data.xlsx` — 原始数据表格
2. `regression_report.txt` — 完整文字报告
3. `01_regression_results.png` — 回归结果可视化（精简为1张核心图）

## 报告必备内容

### 一、回归结果汇报
- **系数表**：包含系数、稳健标准误、t/z值、p值、95%置信区间
- **拟合优度**：R²、调整R²、F统计量及p值
- **信息准则**：AIC、BIC（模型选择时）
- **观测数**：明确样本量

### 二、经济理论解读
- **避免**：仅陈述数字（如"系数是-0.22"）
- **必须**：结合经济理论解释系数方向和大小
  - "负号意味着..."
  - "绝对值大小意味着..."
  - "从首次UP到第5次复刻，流水下降了约X%"

### 三、假设检验
- **t检验**：每个系数的显著性（H₀: β=0）
- **F检验**：模型整体显著性
- **经济意义 vs 统计显著性**：区分"统计上不显著但经济上有意义"的情况
- **稳健性**：HC3/聚类标准误、异方差检验、正态性检验

## 图表精简原则

**只保留1张核心图**：
- 散点图 + 拟合线（展示核心X-Y关系）
- 或：边际效应图（展示预测值变化）

**删除**：
- ❌ 残差图（文字报告提及即可）
- ❌ Q-Q图（JB检验已覆盖）
- ❌ 上下半箱线图（如系数不显著）

## 模型设定规范

1. **避免共线性陷阱**：检查变量间是否由定义式关联
   - 例：revenue = total × ratio → 不能同时放 ln(total) 和 ln(ratio)
2. **FE选择**：个体FE优先于时间FE，除非研究时间效应
3. **标准误**：默认使用 HC3 稳健标准误

## 错误检查清单

- [ ] 是否误将定义式同时放入解释变量？
- [ ] R²是否接近1.0（可能是共线性）？
- [ ] 系数符号是否符合经济直觉？
- [ ] p值和置信区间是否一致？
- [ ] 样本量是否足够支持模型复杂度？
